# Connect 4

## Project Overview

A modern, interactive Connect 4 game built with React, TypeScript, Material-UI, and Framer Motion. Features beautiful animations, an interactive particle background, and a polished UI suitable for players of all ages.

## Features

- **Interactive Gameplay**: Classic Connect 4 mechanics with modern UX
- **Animations**: Smooth Framer Motion animations for pieces and wins
- **Particle Background**: Dynamic interactive particle effects
- **Responsive Design**: Works on desktop and tablet
- **Material-UI Components**: Professional UI components

## Tech Stack

- **Frontend**: React 19.2 + TypeScript 5.9
- **Build Tool**: Vite 7.2
- **UI Framework**: Material-UI
- **Animations**: Framer Motion
- **Styling**: MUI theming

## How to Play

1. Click on a column to drop your piece
2. First to connect 4 pieces in a row (horizontal, vertical, or diagonal) wins
3. Choose to play against AI or another player
